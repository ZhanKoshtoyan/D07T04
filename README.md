# D07T04. Указатели и массивы

Учебный проект школы 21 (School 21 / Ecole 42), посвящённый работе с указателями, массивами и передаче данных в функции по указателю. Все программы читают данные из `stdin` и выводят результат в `stdout`.

## Стек и требования

- Язык: **C** (стандарт **C11**)
- Компилятор: **gcc**
- Флаги сборки: `-Wall -Wextra -Werror`
- Стиль кода: **Google C++ Style Guide**
- Глобальные переменные запрещены
- **Динамическая память запрещена** (только статические массивы)
- Передача массивов в функции — **только по указателю**
- В квестах 5–8 использование `<stdlib.h>` **запрещено**
- Разрешённые библиотеки: `<stdio.h>`, `<math.h>` (последняя — только там, где действительно нужна)
- Вывод программ **не должен заканчиваться переводом строки**, если это не предусмотрено форматом

## Сборка

Пример для `maxmin.c`:

```bash
gcc -Wall -Wextra -Werror -std=c11 src/maxmin.c -o maxmin
./maxmin
```

Для программы `search.c`, использующей `<math.h>` (`sqrt`), добавьте `-lm`:

```bash
gcc -Wall -Wextra -Werror -std=c11 src/search.c -o search -lm
```

Остальные программы собираются без `-lm`.

## Программы

### 1. `maxmin.c` — Максимум и минимум из трёх чисел

Принимает три целых числа и выводит максимум и минимум через пробел. Поиск оформлен отдельной функцией `maxmin`, которая возвращает результаты через указатели.

- **Вход:** три целых числа
- **Выход:** `<max> <min>`
- **Ошибка ввода / выход за пределы `int`:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход      | Выход |
|-----------|-------|
| `1 2 3`   | `3 1` |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/maxmin.c -o maxmin
echo "1 2 3" | ./maxmin
# 3 1
```

### 2. `squaring.c` — Возведение массива в квадрат

Принимает длину массива (`1..10`), затем сами целые числа. Выводит массив, каждый элемент которого возведён в квадрат.

- **Вход:** `N` (1..10), затем `N` целых чисел
- **Выход:** `N` квадратов через пробел
- **Ошибка ввода / переполнение `int` при возведении в квадрат:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход                | Выход   |
|---------------------|---------|
| `3`<br/>`1 2 3`     | `1 4 9` |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/squaring.c -o squaring
printf "3\n1 2 3\n" | ./squaring
# 1 4 9
```

### 3. `stat.c` — Статистические метрики массива

Принимает длину массива (`1..10`), затем сами целые числа. Выводит массив на первой строке, затем на новой строке — статистические метрики: максимум, минимум, математическое ожидание и дисперсию (как для дискретного равномерного распределения).

- **Вход:** `N` (1..10), затем `N` целых чисел
- **Выход:** массив через пробел, затем `\n`, затем `<max> <min> <mean> <variance>` (вещественные — с точностью 6 знаков после запятой)
- **Ошибка ввода:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход                | Выход                                       |
|---------------------|---------------------------------------------|
| `4`<br/>`1 2 3 4`   | `1 2 3 4`<br/>`4 1 2.500000 1.250000`       |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/stat.c -o stat
printf "4\n1 2 3 4\n" | ./stat
# 1 2 3 4
# 4 1 2.500000 1.250000
```

### 4. `search.c` — Поиск по правилу трёх сигм

Принимает длину массива (до 30) и сам массив целых чисел. Находит **первое** число, которое одновременно:

- чётное;
- не равно `0`;
- больше или равно математическому ожиданию;
- не превышает `mean + 3·σ` (правило трёх сигм).

Если подходящего числа нет — выводит `0`.

- **Вход:** `N` (1..30), затем `N` целых чисел
- **Выход:** найденное число или `0`
- **Ошибка ввода:** `n/a`
- **Библиотеки:** `<stdio.h>`, `<math.h>` (нужен `-lm`)

| Вход                | Выход |
|---------------------|-------|
| `4`<br/>`1 2 3 4`   | `4`   |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/search.c -o search -lm
printf "4\n1 2 3 4\n" | ./search
# 4
```

### 5. `sort.c` — Сортировка массива из 10 чисел

Принимает ровно 10 целых чисел и выводит их, отсортированными по возрастанию. Реализована сортировка пузырьком, без `<stdlib.h>` (по условию задания). Функции чтения, сортировки и вывода выделены отдельно, массив передаётся только по указателю.

- **Вход:** ровно 10 целых чисел
- **Выход:** 10 чисел по возрастанию через пробел
- **Ошибка ввода:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход                                | Выход                             |
|-------------------------------------|-----------------------------------|
| `4 3 9 0 1 2 100 2 7 -1`            | `-1 0 1 2 2 3 4 7 9 100`          |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/sort.c -o sort
echo "4 3 9 0 1 2 100 2 7 -1" | ./sort
# -1 0 1 2 2 3 4 7 9 100
```

### 6. `key9part1.c` — Сумма чётных и делители

Принимает длину массива (`1..10`) и сам массив. Вычисляет сумму чётных ненулевых элементов. Затем формирует новый массив из тех элементов исходного (кроме `0`), на которые сумма делится нацело. Выводит сумму на отдельной строке, ниже — сформированный массив через пробел.

- **Вход:** `N` (1..10), затем `N` целых чисел
- **Выход:** сумма чётных (ненулевых) на первой строке, затем массив делителей через пробел
- **Ошибка / нет чётных элементов:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход                                          | Выход                     |
|-----------------------------------------------|---------------------------|
| `10`<br/>`4 3 9 0 1 2 0 2 7 -1`               | `8`<br/>`4 1 2 2 -1`      |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/key9part1.c -o key9part1
printf "10\n4 3 9 0 1 2 0 2 7 -1\n" | ./key9part1
# 8
# 4 1 2 2 -1
```

### 7. `cycle_shift.c` — Циклический сдвиг массива

Принимает длину массива (`1..10`), сам массив и число `c` — на сколько элементов сдвинуть массив влево. При отрицательном `c` сдвиг выполняется вправо. Сдвиг циклический: элементы, «выпавшие» с одной стороны, появляются с другой.

- **Вход:** `N` (1..10), `N` целых чисел, `c` (целое)
- **Выход:** сдвинутый массив через пробел
- **Ошибка ввода:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход                                              | Выход                             |
|---------------------------------------------------|-----------------------------------|
| `10`<br/>`4 3 9 0 1 2 0 2 7 -1`<br/>`2`           | `9 0 1 2 0 2 7 -1 4 3`            |

```bash
gcc -Wall -Wextra -Werror -std=c11 src/cycle_shift.c -o cycle_shift
printf "10\n4 3 9 0 1 2 0 2 7 -1\n2\n" | ./cycle_shift
# 9 0 1 2 0 2 7 -1 4 3
```

### 8. `key9part2.c` — Длинная арифметика: сложение и вычитание

Принимает два «длинных» числа. Формат каждого числа: сначала **длина** (количество цифр), затем сами **цифры** через пробел (каждая цифра — отдельное целое от `0` до `9`). Максимальная длина — 100 цифр.

Программа выводит:
- на первой строке — **сумму** чисел (в виде последовательности цифр через пробел);
- на второй строке — **разность** (уменьшаемое − вычитаемое). Если вычитаемое больше уменьшаемого, выводится `n/a`.

- **Вход:** `<len1> <d1> <d2> ... <d_len1> <len2> <e1> <e2> ... <e_len2>`
- **Выход:** сумма на первой строке, разность на второй
- **Ошибка ввода / отрицательная разность:** `n/a`
- **Библиотеки:** `<stdio.h>`

| Вход                                                                     | Выход                                                                                       |
|--------------------------------------------------------------------------|---------------------------------------------------------------------------------------------|
| `19 1 9 4 4 6 7 4 4 0 7 3 7 0 9 5 5 1 6 1 2 2 9`                          | `1 9 4 4 6 7 4 4 0 7 3 7 0 9 5 5 1 9 0`<br/>`1 9 4 4 6 7 4 4 0 7 3 7 0 9 5 5 1 3 2`        |
| `2 1 0 1 1`                                                              | `1 1`<br/>`9`                                                                               |

В первом примере: первое число — `1944674407370955161`, второе — `29`. Сумма = `1944674407370955190`, разность = `1944674407370955132`. Во втором: `10` и `1`, сумма `11`, разность `9`.

```bash
gcc -Wall -Wextra -Werror -std=c11 src/key9part2.c -o key9part2
echo "2 1 0 1 1" | ./key9part2
# 1 1
# 9
```
